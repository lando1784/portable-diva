# Portable Diva

Strumenti per avere un avatar ricorrente e coerente tra giochi diversi.
Il repository è una collezione di librerie ed eseguibili indipendenti, ognuno in una sua sottocartella.

| Progetto | Cosa fa |
|---|---|
| [`diy-diva/`](diy-diva/) | Descrive l'avatar una volta sola in un formato indipendente dai giochi e genera, per l'editor di ogni gioco, una "ricetta" da seguire a mano (voci da scegliere, posizioni degli slider, colori). |
